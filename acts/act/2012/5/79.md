## PART XIII
# 79. Amendments to the Code of Police Laws.
(1) This Part amends the Code of Police Laws, and it shall be read and construed as one with the Code of Police Laws, hereinafter in this Part referred to as ''the Code''.
(2) The provisions of this Part shall come into force on such date as the Minister responsible for the Police may, by order in the Gazette, establish.
- See Cap. 10.
