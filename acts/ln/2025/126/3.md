# 3. Conflict between regulations.
In the event that any provision of these regulations is in conflict with the provisions of the Waste Management (Packaging and Packaging Waste) Regulations, the Waste Regulations or the Extended Producer Responsibility Framework Regulations, these regulations shall prevail.
- See S.L. 549.43.
- See S.L. 549.63.
- See S.L. 549.141.
