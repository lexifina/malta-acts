## SCHEDULE IV
# schedule-iv
EMISSION LIMIT VALUES FOR LIQUID FUELS
Emission limit values expressed in mg.Nm-3 and shall be calculated at a temperature 273 K, a pressure of 101.3 kPa and at an oxygen content of 3% to be applied by combustion plants pursuant to regulation 6.
The emission limit values set out in this schedule apply to the emissions of each common stack in relation to the total rated thermal input of the entire combustion plant.
A. Emission Limit values for SO2.
Rated Thermal Input (PTh) Emission Limit Value (ELV)
350 mg SO2.Nm-3
50MWTh ≤ PTh ≤ 100 MWTh
200 mg SO2.Nm-3
100MWTh < PTh ≤ 300MWTh
150 mg SO2.Nm-3
PTh > 300MWTh
B. Emission Limit values for NOX measured as NO2.
Rated Thermal Input (PTh) Emission Limit Value (ELV)
300 mg NO2.Nm-3
50MWTh ≤ PTh ≤ 100 MWTh
150 mg NO2.Nm-3
100MWTh < PTh ≤ 300MWTh
100 mg NO2.Nm-3
PTh > 300MWTh
C. Emission Limit values for dust.
Rated Thermal Input (PTh) Emission Limit Value (ELV)
20 mg dust.Nm-3
50MWTh ≤ PTh ≤ 300 MWTh
10 mg dust.Nm-3
PTh > 300MWTh
D. Emission Limit value for CO.
For all plants 100 mg CO.Nm-3.
