# 5. Appropriate certificates for seafarers.
These regulations also provide for the issue of appropriate certificates for any seafarer serving in the capacity set out in column 1 of the table below. A person shall only be entitled to be issued with such an appropriate certificate if such person complies with the criteria in regulations annexed to the Convention set out in column 2 of the table in relation to that entry and in accordance with the conditions set out in the First Schedule.
