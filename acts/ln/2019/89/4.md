# 4. Requirements for the accessibility of websites and mobile applications.
Public sector bodies shall take the necessary measures to make their websites and mobile applications more accessible by making them:
(a) perceivable, meaning that information and user interface components are presentable to users in ways they can perceive;
(b) operable, meaning that user interface components and navigation are operable;
(c) understandable, meaning that information and the operation of the user interface are understandable; and
(d) robust, meaning that content must be robust enough to be interpreted in a reliable manner by a wide variety of user agents, including assistive technologies.
