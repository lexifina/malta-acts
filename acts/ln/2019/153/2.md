# 2. Amends regulation 2 of the principal regulations.
In regulation 2 of the principal regulations, the definition "network access point" shall be substituted by the following:
" "network access point" is a fixed terrestrial short range device in a data network that acts as a connection point for the other short range devices in the data network to service platforms located outside that data network. The term data network refers to several short range devices, including the network access point, as network components and to the wireless connections between them;".
