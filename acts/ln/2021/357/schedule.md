# schedule
Data to be submitted to the Superintendent with each notified test result:
(a) tested person's identification document number (in order of preference: Malta identity card number or passport
number or Malta hospital identity number);
(b) tested person's first name and surname;
(c) tested person's date of birth;
(d) tested person's sex according to official documentation;
(e) tested person's nationality;
(f) tested person's contact number in Malta (a mobile number is preferred);
(g) tested person's email address (when available);
(h) tested person's postal address in Malta;
(i) test type;
(j) test name (only in case of rapid antigen test);
(k) test manufacturer (only in case of rapid antigen test);
(l) testing facility name;
(m) test result;
(n) test reason (only in case of rapid antigen test);
(o) test specimen collection date and time; and
(p) test result date and time (only in case of nucleic acid amplification test).
