# 2. Interpretation.
(1) In these regulations, unless the context otherwise requires:
"EUROCONTROL" has the same meaning assigned to it by the EUROCONTROL Act;
"IFR" means Instrument Flight Rules.
(2) Expressions used in these regulations shall, unless the context otherwise requires, have the same respective meanings as in the Air Navigation Order.
- See Cap. 333.
- See S.L. 499.09.
