# 30. Port facility security plan approval.
The Designated Authority must approve a port facility security plan, or its amendments, if it>-
(a) is consistent with>
(i) the purposes of these regulations< and
(ii) the security assessment for that port facility< and
(b) complies with the>
(i) requirements of these regulations< and
(ii) requirements prescribed by the Designated Authority from time to time.
