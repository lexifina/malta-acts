## Import Duties Act;".
# 3. Amends regulation 5 of the principal regulations.
Immediately after sub-regulation (3) of regulation 5 of the principal regulations, there shall be addeed the following new sub-regulations:
"(4) It shall not be possible to apply for or use, more than one of the following licences, from the same premises:
(a) a licence for a commercial activity which consists of, or includes, retail sale of food, beverages (including alcoholic beverages) and tobacco in specialised stores selling predominantly bread, cakes, flour confectionery and sugar confectionery;
(b) a licence for a commercial activity which consists of or includes retail sale of food, beverages (excluding alcoholic beverages) and tobacco in specialised stores selling predominantly bread, cakes, flour confectionery and sugar confectionery;
(c) any other licence for any other commercial activity.
(5) All licence holders which, at the date of coming into force of these regulations, are licensed as confectionaries or under type code 52.24 shall have until the 31st May 2011 to choose between type code 52.24(A) and 52.24(B) and to notify in writing the Trading Licences Unit:
Provided that licence holders who do not effect such choice shall be, as from that date, considered to hold a type code 52.24(B) licence:
Provided further that the licence holders referred to above may at any time apply to the Trade Licensing Unit to change from type code 52.24(A) to type code 52.24(B) or from type code 52.24(B) to type code 52.24(A).".
