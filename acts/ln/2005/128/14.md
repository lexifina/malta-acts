# 14. Manufacturer's code.
(1) Schedule XX to these regulations contains a list of the recreational craft manufacturers established in Malta and the codes assigned to them by the Malta Maritime Authority.
(2) The code consists of three letters taken from the manufacturer's name.
(3) The manufacturer's code must be used for the craft identification (Annex I, part A, point 2.1 of the Directive, set out in Schedule I, part A, point 2.1 hereto).
